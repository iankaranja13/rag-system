# 🏥 Medical Research Assistant

A sophisticated RAG (Retrieval-Augmented Generation) system specialized for medical literature analysis and research assistance.

## 🌟 Features

- **Intelligent Document Processing**: Support for PDFs, text files, websites, and YouTube transcripts
- **Advanced Retrieval**: Dense, sparse, and hybrid retrieval methods with reranking
- **Medical Specialization**: Optimized for healthcare and medical research content
- **Interactive Web Interface**: Built with Streamlit for ease of use
- **Multiple Document Collections**: Organize documents by medical specialty
- **Comparative Analysis**: Compare findings across different document collections
- **Export Capabilities**: Save queries and results for future reference
